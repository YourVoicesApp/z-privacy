Behaviour — the Original side Every act, and what it does in each state. The mistake in this app will not be a colour; it will be what happens on the press. Hard rule · nothing on this side can reach the network
Z Protect five states DISABLED Nothing is selected → greyed, and the hint beside it reads Select text, then Protect. READY A new, unknown selection → the dialog: Once · This conversation · Always, a Category the pack has guessed, and Protect all N matches when there are more. KNOWN Already protected → no dialog. A line says «Already protected as Z_PERSON_72A, from Z Vault · CLIENT #17», and the only act offered is Undo Protection. ASKS A new spelling of something known → «Add as an alias of CLIENT #17» (offered first) or «Make a new identity». Alias keeps the same token; a new identity gets its own. SNAPS The selection cuts a protected item in half, or spans several → it snaps to whole items, says how many, and protects each under its own token.
Rescan the scan itself is not a screen ON IMPORT Runs by itself, with no dialog, inside the Workspace. The band under the header reports it. Nobody has to press anything to be protected. READY Pressed → scans again with the same types. Items you protected by hand are never touched; automatic ones are recomputed; the counts update in place. OPTIONS The chevron opens the type list — Scan options. That screen is for detail and for turning a type off in this document; it is not the way to be scanned. VAULT LOCKED The vault layer is skipped and the band says so in words. The general rules and the pack still run, so an IBAN is still caught — but not who.
Review 2 the gate before Send DISABLED No suggestions → greyed, and the badge is gone, not zero. Nothing is waiting for you. READY Badge = how many are open. It opens the list of all nine items in three groups — auto protected, suggested, manual — each with the rule that flagged it. WALKING One suggestion at a time, with its sentence around it. Skip leaves it in the clear and still counted — skipping is not deciding. DONE The last one answered → the badge goes, the wavy marks go, and Send stops warning.
Undo Protection one step back DISABLED Nothing has been protected by hand in this document yet. READY Takes back the last protection act. «Protect all 4 matches» came in as one act, so it goes out as one act. VAULT ITEM Undoing something the vault found frees it here only. The entity stays, and a line says so — the next document finds it again. ASKS If that act also created a vault entity, undo asks the second question: keep the entity, or remove it too?
Protect All Matches 4 one token, every place DISABLED No selection, or the selection appears only once — then it is the same as Protect, and the count is hidden. READY The number on the button is how many places it found. All of them get the same token — otherwise the model reads them as different people. SHOWS Matches that are written differently — «Herr Müller», «T. Müller» — are listed before it acts, and become aliases of the same value.

READY Opens the value form with the kind already guessed, and asks the one question that matters: which identity does this belong to — an existing one, or a new one?
