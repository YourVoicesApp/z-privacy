Was Windows sagen wird, und warum

Dieses Installationsprogramm hat niemand signiert. Eine Datei, die Ihr Browser herunterlädt, trägt die Markierung, dass sie aus dem Internet stammt; deshalb zeigt Windows beim ersten Start statt des Installationsprogramms eine blaue Seite — «Der Computer wurde durch Windows geschützt». Diese Seite handelt von der fehlenden Signatur und von nichts sonst: sie sagt, dass Windows den Herausgeber nicht kennt, nicht dass es in der Datei etwas gefunden hätte.

Der Weg hindurch sind zwei Klicks: «Weitere Informationen», dann «Trotzdem ausführen». Auf dem Rechner, auf dem wir das gemessen haben, wurde die zweite Schaltfläche jedes Mal angeboten; sollten wir je erleben, dass Windows die Datei ganz blockiert, ändert sich dieser Satz zuerst hier.

Nichts verlangt Administratorrechte. Z Privacy installiert nur für Sie, in Ihrem eigenen Ordner, und weder die blaue Seite noch das Installationsprogramm fragt nach dem Kennwort des Rechners.

Die Seite kommt nur einmal. Nach «Trotzdem ausführen» nimmt Windows die Markierung von dieser Datei, und derselbe Start zeigt beim nächsten Mal nichts mehr.

Die letzte Seite des Installationsprogramms bietet an, Z Privacy für Sie zu starten, und das Häkchen ist schon gesetzt. Entfernen Sie das Häkchen, wenn Sie Z Privacy lieber selbst starten.

Weil keine Signatur sagt, dass die Datei von uns ist, sagt es der Fingerabdruck auf dieser Seite: führen Sie die eine Zeile oben aus und vergleichen Sie beide, Zeichen für Zeichen. Er steht hier, auf einer Seite von z-privacy.com, und sonst nirgends.

Ein signiertes Installationsprogramm und mit ihm das Paket für den Microsoft Store folgen, sobald ein echtes Code-Signing-Zertifikat es signiert. Ein Datum dafür versprechen wir nicht, und nichts auf dieser Seite wartet darauf.

Was ein Modell, das es nicht gebaut hat, zu unseren Aussagen sagt

Was dieses Produkt über sich selbst behauptet, wird einem Modell vorgelegt, das am Bauen keinen Anteil hatte, und sein Bericht gehört neben die Datei, die Sie gleich herunterladen, und nicht in eine Schublade. Er ist von dieser Zeile aus verlinkt, sobald er veröffentlicht ist; solange die Zeile keinen Link trägt, gibt es noch keinen zu lesen.
