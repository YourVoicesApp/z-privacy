Arabic PDFs, and what Z Privacy now refuses

Some Arabic PDFs carry their text in the shapes a layout program drew, so the order Z Privacy reads is the drawing’s and the words come out backwards. Such a file is now refused by name, with the reason and a pointer to a Word or plain-text file: Z Privacy will not protect a text it has read backwards. An Arabic PDF with a sound text layer in logical order is not refused for this reason — in the cases tested it reads as the same text as `.txt` — so what is refused here is not «Arabic» and not «right to left»; such a file may still be refused for another reason, such as encryption or a missing text layer. Two limits remain: a file drawn backwards that still carries ordinary letters is not caught by this, and a protected PDF that Z Privacy itself wrote in Arabic can no longer be brought in as a document to protect — the door that only reads such a file is unchanged.

What Windows will say, and why

Nothing has signed this installer. A file your browser downloads is marked as having come from the internet, so the first time you start it Windows shows a blue page — «Windows protected your PC» — instead of the installer. That page is about the missing signature and about nothing else: it says Windows does not recognise who published the file, not that it found anything wrong inside it.

The way through is two clicks: «More info», then «Run anyway». On the machine where this was measured the second button was offered every time; if we ever see Windows refuse outright, that sentence will change here first.

Nothing asks for an administrator. Z Privacy installs for you alone, in your own folder, and neither the blue page nor the installer asks for the password of the machine.

It comes once. After «Run anyway» Windows takes the mark off that file, so starting the same installer again shows nothing.

The last page of the installer offers to start Z Privacy for you, with the box already ticked. Untick it if you would rather start it yourself.

Because no signature says the file is ours, the fingerprint on this page is what says it: run the one line above and compare the two, character for character. It is printed here, on a page served from z-privacy.com, and nowhere else.

A signed installer, and with it the Microsoft Store package, follows when a real code-signing certificate signs it. There is no date promised for that, and nothing on this page waits for it.
