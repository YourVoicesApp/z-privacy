# تدقيق تاريخ Git قبل النشر — ٣٠ سبتمبر ٢٠٢٦

شرطه قبل أيّ مستودع عامّ: **كلّ التاريخ، لا HEAD وحده** — لأنّ حذف ملفّ من
HEAD لا يُخرجه من التاريخ.

المدى: **٧٩ commit**، و**٢٥٤ ملفّاً** وُجد يوماً في الشجرة.

## النتيجة: نظيف، ببندٍ واحد مقصود

| ما بحثتُ عنه | النتيجة |
|---|---|
| مفاتيح API أو اعتمادات حقيقيّة (`sk-…`, `AKIA…`, `PRIVATE KEY`, `api_key=`) | **لا شيء** في أيّ commit |
| صناديق بريد حقيقيّة (gmail/outlook/web.de/…) | **لا شيء** |
| ملفّات خزنة أو إعدادات (`*.zv`, `*.zcfg`) | **لم تُودَع قطّ** |
| صور أو لقطات أو سجلّات (`*.png`, `*.log`, `*.xwd`, …) | **لم تُودَع قطّ** |
| PDF/DOCX من عملٍ حقيقيّ | **لا شيء** — الوحيد `malformed.docx` صناعيّ، موسوم `ZXQ-DOCX-PARTIAL-77220` |
| أسماء عملاء أو أشخاص حقيقيّين | كلّها أسماء fixture مخترعة: Nordstern Consulting GmbH · Thomas Müller · Anna Weber · Bernd Bauer · Erik Lindqvist |
| عبارات مرور | عباراتُ اختبارٍ ألمانيّة ظاهرة الاصطناع («ein gutes Passwort für den Test») — لا سرّ |
| بنية تحتيّة لمشروعٍ آخر | `192.168.1.10` و`192.168.1.50` فقط، وهما مثالان من المدى الخاصّ في اختبارات «ليس loopback». لا خوادم YourVoices |
| أكبر blob | `frb_generated.rs` بـ٣١٤ ك.ب — كودٌ مولَّد، لا بيانات |

## مسارٌ مطلق بقي عن عمد

```text
redteam/2026-09-28/original/Cargo.toml:7
z_core = { path = "/home/monopeaks/mono-privacy/z_core" }
```

هذا **ملفّ الفريق الأحمر نفسه**، و`original/` لا يُعدَّل — وتعديله يكسر
G21 ويُبطل دعوى «المهاجم كما جرى». والـREADME يقول للقارئ أن يعدّل المسار
في نسخته. يكشف اسم مجلّد البيت `monopeaks` ولا شيء غيره.

**وأُصلح المسار المطلق الآخر:** `document_journey.rs` كان يقرأ الـfixture من
مجلّد البيت، فكان يسقط في كلّ مكانٍ آخر إلى نسخةٍ يعيد بناءها — أي أنّ
الاختبار لم يكن يلمس البايتات التي كسرت المحلّل إلّا على جهازٍ واحد. صار
يقرأ النسخة المُودَعة.

## هويّة المؤلّف — أُعيدت كتابتها ٣٠ سبتمبر

كان التاريخ كلّه يحمل بريده الشخصيّ/السابق. وبقراره صار:

```text
Anas <yourvoices.app@mono-peak.com>
```

**بريد المنصّة**، وهو الصحيح لمستودعٍ تملكه المنصّة. وأُعيدت الكتابة قبل
أوّل دفع، لأنّها بعده تعني تاريخين عند كلّ من استنسخ.

والعنوان القديم أُزيل من **كلّ commit**: من حقلَي author وcommitter، ومن
حقل tagger في الوسم، ومن نصّ هذه الورقة نفسها في نسخها القديمة — فذِكرُه
هنا كان آخر موضعٍ يبقيه في التاريخ.

والمحتوى لم يتغيّر: شجرة HEAD وشجرة الوسم بالبصمة نفسها قبل وبعد.

## الخلاصة

لا يوجد ما يمنع النشر تقنيّاً، والتاريخ نظيفٌ من العنوان القديم. الباقي
قراره وقد اتُّخذ: **YourVoices / Z-Privacy / Public**.
