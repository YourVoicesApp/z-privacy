## خ3 · Zero-width and NFD blind the German salutation

**Measured:** pack `de`, `Sehr geehrter Herr Mar<U+200B>kus Weber,` → no finding; `Herr` + NFD `Müller` (u + combining diaeresis) → Thomas Auto, Müller missed; NFC control → both Auto. `people.rs` `name_shaped` asks `char::is_alphabetic`, which a combining mark and a format character both fail.
**Build:** the shape test reads the word as a person reads it — NFC-normalised for the test only, with format characters (`Cf`: ZWSP, ZWNJ, ZWJ, soft hyphen, the bidi marks that are not ours) skipped — while the span it reports is the original's, byte for byte, so the token replaces exactly what stood there and the document reads as it read (G3: NFC and NFD are one value; `text::nfc` exists). Never NFKC. One function that answers «is this a letter of a name» for every pack, with its own test: ZWSP inside a name, NFD umlaut, a soft hyphen, and the control that a real bidi isolate we wrote is not treated as part of a word.
