# 003 · الأخطاء والعقد

**المرحلة:** M1 · **الحالة:** تمّت
**ملاحظة:** نزلت في commit واحد مع 004، لأنّ `api.rs` يحمل الاثنين ولا يُقسم نصفين بصدق.

## المطلوب (تصحيح المالك الأوّل)
لا `todo!()`: كلّ دالّة تُرجع `ApiResult<T>`، والحالة غير المبنيّة `Err(ApiError::NotImplemented)`.
الثابت: **لا panic يعبر حدود Rust ↔ Flutter.**

## ما دخل
- `ApiResult<T>` و`ApiError` بأحد عشر فرعاً، كلٌّ يحمل ما يحتاجه الشرح: `StalePayload { expected, got }`، `ImportRefused { reason }`، `BadSpan { reason }`…
- العقد كلّه: **٣٠ دالّة**، جلسة · مستند · حماية · مراجعة · رموز · حِمْل · جواب · خزنة · ملفّات · حزم · مزوّدون.
- الإزاحات **UTF-16** لأنّ سلاسل Dart كذلك، و`Span` خارج الحدود أو في وسط حرف ⇒ `BadSpan`. اختبارات `text.rs` تُثبتها على «Müller» وعلى رمز تعبيري.
- كلّ عدد يعبر الجسر `u32` لا `u64`/`usize`: frb يحوّل الأخيرين إلى `BigInt` في Dart، وليس في الدنيا مستندٌ فيه أربعة مليارات وحدة.

## شيئان اكتشفناهما هنا، وكلاهما مهمّ
1. **البوّابة G2 اصطادت أوّل شيء في أوّل يوم:** `send(handle, provider_id: String)`. لم أخفّف البوّابة — أضفتُ نوعاً `ProviderId`، فبقيت البوّابة غبيّة صارمة («لا String في توقيع إرسال») ولا تُحاوَر.
2. **frb يجعل أنواع الصندوق الآخر opaque:** أي أنّ Dart كان سيستلم `ApiError` و`ProtectOutcome` كمقبضين مغلقين، فلا يعرف الفرع ولا الحقول — وهذا يقتل ألواح السلوك. الحلّ: `scripts/gen_mirrors.py` يولّد إعلانات الشكل من ملفّ العقد نفسه (٢٧ نوعاً)، و**البوّابة G12** تفشل البناء إن انحرف المولّد عن العقد. مصدر واحد للحقيقة، والانحراف مستحيل صامتاً.
   النتيجة في Dart: `sealed class ApiError`، و`ApiError.stalePayload(expected:, got:)`، و`sealed class ProtectOutcome` — الواجهة تستطيع أن تقرأ **لماذا**، لا أن تعرف أنّ شيئاً فشل.
