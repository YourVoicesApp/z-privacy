## The session's contract — three pillars, the rest is luxury

His words: *«ثلاثة أمور في الجلسة: المفتاح، الملفات المرسلة إلى الشات أو
القادمة من الشات، ولغة الجلسة... وما دون ذلك رفاهية ليس هناك مشكلة إذا لم
تظهر»*. So the session MUST hold, across an application restart, measured by
a guard each:

1. **The key** — which key (and which model holding it) this session's
   conversation ran through;
2. **The exchanged material** — what went to the chat and what came back
   (format 2 already carries the turns; the guard proves a reopened session
   shows them);
3. **The session's language.**

Close the app, reopen, open the session: the three stand. Anything else that
got lost is not chased.

## The four repairs

**A — Profiles recedes (075a, design seat).** The owner did not understand
the Profiles dialog because he has never needed it: one profile exists. While
the vault holds exactly one profile, no PROFILE control in the header and no
dialog that can interrupt; the door returns the day a second profile is
actually created (or from the board, for whoever goes looking). Same exile
pattern as the AI catalog (067).

**B — Pressing a session opens its conversation (075b, design seat, core if
the door needs it).** Today the Sessions list selects and leaves you where
you stood. His words: *«الجلسة تحفظ الملفات التي ذهبت والإجابات... الضغط على
اسم الجلسة»* يجب أن يُعيد شاشتها. Wherever a session's name is pressed, its
conversation screen opens with what the app kept: what left, what returned,
what followed. Selection without showing is half an answer.

**C — The three pillars, held and guarded (075c, programmer).** Measure
first: which of the three survives a restart TODAY, each with `file:line` of
where it is written and read — then fix what does not, smallest honest
commits. The language the session was born with; the key/model identity the
conversation used (the NAME the person saw, never the secret); the turns.
Guards: reopen-after-restart tests, one per pillar.

**D — The language question is asked once per session (075d, both seats).**
Depends on C. His words: *«الإنسان لا يحب التكرار»*. The first document of a
session asks (or the session's birth sets it); every later import inherits
the session language silently. Changing it stays possible where it already
lives in the header — a control, not an interruption.
